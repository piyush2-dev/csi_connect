
CSI Connect is a modern, responsive digital portal for the **CSI Student Chapter, Department of Information Technology, SVPCET**, built with a lightweight single-page architecture using **HTML5, CSS3, and Vanilla JavaScript**.

Features a premium blue-white UI, animated interactions, responsive layouts, dynamic visual effects, and centralized access to CSI's digital platforms.

**Tech Stack:** HTML5 • CSS3 • JavaScript • SVG • Responsive Design
